## Stay up to date

1. Open an app’s fork using the links above.
2. Click **Sync fork**, then **Update branch** when available.
3. If there are conflicts with your own changes, review and merge them before updating. Do not discard your changes just to force a sync.

For a local copy, commit or stash your work first, then run `git pull --ff-only` inside the app folder after syncing on GitHub. If Git reports diverged history, stop and review the changes.

## Local organization

Keep the independent repositories side by side inside a folder named `Creative-Magic`. This hub contains links and instructions; it does not duplicate the app source code.
